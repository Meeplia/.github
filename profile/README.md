# Meeplia

Meeplia is an early-stage platform for creating, discovering, and playing board games with generative AI.

Core ideas:

- Text-to-Game: describe a board game idea and generate a playable prototype.
- AI-assisted play: use AI to explain game state and provide strategic guidance.
- Creator-first board game experiences.

Website: [meeplia.app](https://meeplia.app)

Verified repositories include:

- `meeplia-web`
- `text2game`
- `game-teacher`
- `ai-agents`
